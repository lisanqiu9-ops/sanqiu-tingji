# 三秋听记 v1.0.12

## 更新内容

- **区分自动更新提醒与主动更新弹窗**：后台自动检查发现新版本时改为**右下角无打扰轻量卡片**（不抢当前窗口焦点，不想更新点「暂不更新」或 `×` 立即关闭）；主动点「立即更新」「查看详情」或通过小铃铛/设置检查更新时，切入完整居中更新窗口（顺手将版本号箭头改为清晰矢量图标）
- **升级会议导出为两大类 × 三种格式**：
  - **AI 会议纪要（不含逐字稿）**：新增标准公文表格版《会议纪要》Word（`.docx`，方正小标宋标题 + 仿宋_GB2312 12 行单线黑框表 + 会议议程 / 会议纪要 / 督办事项 + 底部页码，地点/主持人/记录人留白方便按需手填），并同步支持仅纪要 `.md` 与 `.txt`
  - **纪要 + 完整逐字稿（存档版）**：支持 `.docx` / `.md` / `.txt` 三种格式，且 `.txt` 现输出无 Markdown 符号的干净纯文本

## 如何更新

- **已安装旧版本的用户**：点击左上角小铃铛或打开 **设置 › 通用 › 版本与更新 → 检查更新**，点击 **「立即更新」** 一键升级。
- **首次安装的用户**：访问官网 **`https://tingji.liwu.dpdns.org`** 或下载下方 **`SanqiuTingji-Setup.exe`** 双击安装即可。
