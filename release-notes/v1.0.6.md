# 三秋听记 v1.0.6

## 更新内容

- **内置国内直连更新源与公告源**：软件内检查更新、下载轻量增量更新包以及拉取左上角「消息与更新」公告，默认优先走国内直连域名（`tingji.liwu.dpdns.org`），异常时自动无缝回退 GitHub，无需代理即可顺畅升级
- **上线三秋听记产品官网**：访问 `https://tingji.liwu.dpdns.org` 即可在线体验纪要、逐字稿与原声回放效果，并国内直连下载安装包与免安装便携版

## 如何更新

- **已安装 v1.0.5 及以前版本的用户**：点击左上角小铃铛或打开 **设置 › 通用 › 版本与更新 → 检查更新**，点击 **「立即更新」** 一键升级。
- **首次安装的用户**：访问官网 **`https://tingji.liwu.dpdns.org`** 或下载下方 **`SanqiuTingji-Setup.exe`** 双击安装即可。
