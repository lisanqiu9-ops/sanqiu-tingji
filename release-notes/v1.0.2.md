# 三秋听记 v1.0.2

## 更新内容

- **修复 24-bit 无损录音（ALAC / M4A / WAV）导入失败**：补齐音频重采样器对 24-bit 与 8-bit PCM 的解码支持，并改为托管流式重采样压缩，解决手机/录音笔录制的无损 M4A 文件导入报错问题
- **新增应用内检查更新**：在 **设置 › 通用 › 版本与更新** 中新增当前版本展示、**「检查更新」** 一键检测按钮与 **「自动检查新版本」** 开关，后续版本可直接在软件内下载并重启升级
- **优化桌面快捷方式入口**：安装器创建的桌面「三秋听记」快捷方式优先指向 Velopack 根目录入口，跨版本更新更稳定

## 下载与升级

- **已安装 v1.0.1 的用户**：下载下方 **`SanqiuTingji-Setup.exe`** 运行，安装器会自动识别原安装目录，点击 **「更新」** 即可原地覆盖升级（个人会议记录、词库与设置全部保留）；升级到 `v1.0.2` 后，后续版本即可直接在软件内自动/手动检查更新。
- **首次安装的用户**：下载 **`SanqiuTingji-Setup.exe`** 双击安装（默认勾选创建桌面快捷方式，无需管理员权限）。
- **免安装便携版**：下载 **`SanqiuTingji.App-win-Portable.zip`** 解压后运行 `SanqiuTingji.exe`。
