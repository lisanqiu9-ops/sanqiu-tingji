# 三秋听记 v1.0.5

## 更新内容

- **内置电力行业与河南话预置词包（共 287 条）**：在「词库」窗口左下角新增 **「内置行业 / 方言词包…」**，支持按 **电力系统、新能源与算电协同、招投标与工程、河南话常用词** 4 个独立分类一键勾选导入；重复导入只增补新词，不覆盖已有自定义写法
- **加强方言口音与中英混合词纠错规则**：在「设置 › 收听与识别 › 词库」新增 **「方言与口音增强纠错」**（默认开启），3 字及以上长词自动容忍 `uo/e`、`f/h`、`r/l`、`ui/ei` 等常见口音偏移，同时支持 `EMS系统`、`AGC控制`、`10kV配网` 等中英混排术语音近纠错，2 字词继续严格防误伤
- **优化词库匹配索引性能**：改为按首字与归一化拼音分桶查找，词库扩充至数百条依然保持实时字幕流畅响应

## 如何更新

- **已安装 v1.0.4 及以前版本的用户**：点击左上角小铃铛或打开 **设置 › 通用 › 版本与更新 → 检查更新**，点击 **「立即更新」** 一键升级。
- **首次安装的用户**：下载下方 **`SanqiuTingji-Setup.exe`** 双击安装即可。
