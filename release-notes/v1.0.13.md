# 三秋听记 v1.0.13

## 更新内容

- **修复纪要卡片标签与图标偏移**：发言人胶囊、截止日期胶囊不再出现文字上飘与右侧多余空白，与同行汉字严丝合缝居中；风险提示黄色感叹号改为纯矢量图形并与其他列表图标纵横对齐
- **重塑实时听记浮窗**：
  - 移除冗杂的「逐字稿 / 实时纪要」双 Tab，专注简洁的 **「实时听记」** 发言流
  - 将「🗑 结束会议」替换为实心停止方块 + **「结束收听」**，「收起」换为与顶栏统一圆角描边风格的 **「— 最小化」** 按钮，并规范统一顶部「收听中 / 已保存 / 未开始」状态胶囊与计时器样式
  - 新增副栏右上角 **「对方看不到」一键快捷开关**（亮起蓝态 + 斜杠闭眼即开启防共享/防截屏，点一下秒切并同步保存）

## 如何更新

- **已安装旧版本的用户**：点击左上角小铃铛或打开 **设置 › 通用 › 版本与更新 → 检查更新**，点击 **「立即更新」** 一键升级。
- **首次安装的用户**：访问官网 **`https://tingji.liwu.dpdns.org`** 或下载下方 **`SanqiuTingji-Setup.exe`** 双击安装即可。
