# 三秋听记 v1.0.4

## 更新内容

- **新增左上角「消息与更新」小铃铛**：有新版本或重要公告时亮起红点，点击展开轻量毛玻璃通知浮层，支持一键检查更新、查看公告与全部已读；开会录音期间严格免打扰，完全离线时静默跳过
- **升级增量更新底层基线**：将 Velopack 打包标识切为纯 ASCII 路径并启用智能增量差分流程，为 `v1.0.5` 及后续版本开启轻量增量更新（仅下载变更部分，约 1～5 MB）打好基线
- **优化「发现新版本」弹窗排版**：过滤下载说明冗余项与 Markdown 反引号，加宽滚动区边距，更新要点显示更清爽完整

## 如何更新

- **已安装 v1.0.2 / v1.0.3 的用户**：在软件内打开 **设置 › 通用 › 版本与更新 → 检查更新**，点击 **「立即更新」** 一键升级。
- **首次安装的用户**：下载下方 **`SanqiuTingji-Setup.exe`** 双击安装即可。
