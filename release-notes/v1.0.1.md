# 三秋听记 v1.0.1

Windows 本地离线会议转写与智能纪要助手。

## 下载安装

- **推荐下载：`SanqiuTingji-Setup.exe`**
  - 内置运行环境，无需额外安装 .NET，无需管理员权限
  - 支持自选安装目录，默认勾选 **「在桌面创建『三秋听记』快捷方式」**，安装完自动打开主界面
  - 如 Windows 首次弹出 SmartScreen 安全提示，点击 **「更多信息 → 仍要运行」** 即可
- **免安装版：`SanqiuTingji.App-win-Portable.zip`**（解压后双击 `SanqiuTingji.exe` 运行）

## 核心功能

- **双通道本地离线转写**：同时录制电脑系统声音与麦克风（支持腾讯会议、钉钉、飞书、音视频导入），声音仅留在本机
- **发言人自动区分与同名合并**：会后自动声纹校对，重命名相同姓名自动合并并统一色标
- **原声回放与逐字稿联动**：自动保存轻量 16kHz M4A 录音，支持波形跳转、倍速回放与「仅删除录音（保留纪要）」
- **专业词库分类管理 & 就地纠偏**：支持自定义分类目录与按分类导入导出，逐字稿与术语卡片均可原地改词入库
- **双模式 AI 纪要引擎**：在「设置 › AI 引擎」自由切换 **本地 CLI 桥接（免 API Key）** 或 **在线云端 API（DeepSeek / 通义千问 / 豆包 / Kimi / 智谱 / GPT / Gemini）**，亦内置免 API「手工工坊」

## 首次使用提示

1. 首次启动会自动下载约 260 MB 的本机离线语音模型（只需下载一次）。
2. 打开左上角 **⚙️ 设置 → AI 引擎** 选择本地 CLI 或填入云端 API Key 即可一键生成会议纪要。
