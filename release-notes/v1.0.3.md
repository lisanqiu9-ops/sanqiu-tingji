# 三秋听记 v1.0.3

## 更新内容

- **主窗口全局拖拽 & 多文件批量导入**：直接将单个或多个音视频文件拖入主界面任意位置（或导入弹窗任意位置）即可自动进入后台识别队列，支持 WAV、MP3、M4A、MP4、FLAC、MOV、MKV、WEBM 等格式
- **非阻塞后台导入队列与精确进度**：导入不再锁死主窗口，左侧边栏实时显示文件名、排队数、进度百分比、`已识别时长 / 总时长`、动态预估剩余时间与已出句数，可随时取消；识别一完成立即展示逐字稿，原声 M4A 压缩在后台异步完成
- **离线识别提速**：CPU 推理线程数按本机核心自适应调整（4～8 线程），导入弹窗新增 **「同时区分发言人」** 开关（单人录音或赶时间出字时取消可提速约 2～3 倍）
- **会议崩溃 / 断电录音自愈保护**：录音过程每 5 秒自动刷盘；软件启动自动扫描异常中断遗留的 WAV 原始录音，自动修复未封口文件头并合成为 `audio.m4a` 挂回原会议（或新建恢复条目），避免开会中途闪退丢录音

## 如何更新

- **已安装 v1.0.2 的用户**：直接在软件内打开 **设置 › 通用 › 版本与更新 → 检查更新**，点击 **「立即更新」** 即可一键下载并自动重启升级。
- **首次安装或 v1.0.1 用户**：下载下方 **`SanqiuTingji-Setup.exe`** 双击安装或原地覆盖更新。
