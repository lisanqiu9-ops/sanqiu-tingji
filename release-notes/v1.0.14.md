# 三秋听记 v1.0.14

## 更新内容

- **统一「原声回放」时间线为会议真实钟点时间**：原声回放同步逐字稿左侧的时间胶囊现改为精确到秒的真实钟点（如 `20:26:03`），与「纪要」「逐字稿」时间线口径完全一致，悬停提示保留对应音频偏移位置方便精确定位
- **托盘菜单快捷入口与用词统一**：待机状态下右键托盘新增「打开实时听记」入口；收听中菜单与悬停提示统一为「展开实时听记 / 结束收听」

## 如何更新

- **已安装旧版本的用户**：点击左上角小铃铛或打开 **设置 › 通用 › 版本与更新 → 检查更新**，点击 **「立即更新」** 一键升级。
- **首次安装的用户**：访问官网 **`https://tingji.liwu.dpdns.org`** 或下载下方 **`SanqiuTingji-Setup.exe`** 双击安装即可。
