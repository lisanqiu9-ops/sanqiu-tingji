# 三秋听记 v1.0.8

## 更新内容

- **修复导入录音后页面不刷新**：导入音视频完成后自动清空筛选并立即切换到新会议的逐字稿与音频视图，不再停留在上一场会议内容
- **导入音频自动对齐原录制时间**：自动读取 `.m4a/.mp4/.mov` 的「创建媒体日期」（其他格式按文件修改时间推算开始时间），逐字稿、纪要时间线与导出文档均显示真实录制时刻
- **新增 WorkBuddy / CodeBuddy 桥接并修复 CLI 路径报错**：新增腾讯 WorkBuddy 桌面端及 CodeBuddy CLI 一键扫描接入；彻底修复 npm 安装的 Claude / Codex / Gemini CLI 命中无扩展名脚本导致 `Win32=193` 启动失败的问题，自动自愈已有错误路径，并在高级参数新增「浏览…」按钮
- **国内直连模型下载与断点续传**：本地语音识别与声纹模型优先走 ModelScope 国内 CDN 与自有国内镜像节点（`tingji.liwu.dpdns.org`），增加防卡死超时切源与断点续传，同时支持同目录 `models/` 离线复用，无需代理也能顺畅初始化
- **纪要信息量升级与 3 套新模板**：优化会后完整纪要提示词以保留更多具体数据、观点与细节，并新增「详细纪要（深度整理）」「简短沟通 / 速记」「正式公文纪要」3 套输出模板
- **内置词库自动导入免勾选**：升级后首次启动自动合入电力系统、新能源与算电协同、招投标与工程、河南话常用词 4 个分类（共 287 条），后续手动删改不会被覆盖
- **立即更新前自动确认最新版**：避免软件长时间未关闭时误下旧缓存版本，升级一次直达最新

## 如何更新

- **已安装旧版本的用户**：点击左上角小铃铛或打开 **设置 › 通用 › 版本与更新 → 检查更新**，点击 **「立即更新」** 一键升级。
- **首次安装的用户**：访问官网 **`https://tingji.liwu.dpdns.org`** 或下载下方 **`SanqiuTingji-Setup.exe`** 双击安装即可。
