# 三秋听记 v1.0.10

## 更新内容

- **修复旧版历史会议「最近添加 / 会议时间」排序不生效**：启动加载早于 `v1.0.9` 的旧会议记录时，自动从磁盘目录创建时间还原入库时间，切换排序立即生效
- **更新提醒弹窗支持最小化且不再强制置顶遮挡**：右上角新增矢量最小化按钮（关闭按钮同步改为矢量图标），下载更新时可最小化到任务栏并随时还原

## 如何更新

- **已安装旧版本的用户**：点击左上角小铃铛或打开 **设置 › 通用 › 版本与更新 → 检查更新**，点击 **「立即更新」** 一键升级。
- **首次安装的用户**：访问官网 **`https://tingji.liwu.dpdns.org`** 或下载下方 **`SanqiuTingji-Setup.exe`** 双击安装即可。
