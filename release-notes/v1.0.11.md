# 三秋听记 v1.0.11

## 更新内容

- **移除 WorkBuddy / CodeBuddy 本地 CLI 预设**：由于新版 WorkBuddy 桌面端不共享登录态给外部子进程且无官方个人直连网关，现已下线该预设并清理相关扫描逻辑，避免误导
- **旧配置平滑兼容**：此前曾选中 `workbuddy` 的配置在打开设置或启动时会自动迁移至本机其他可用 CLI（或重置为未启用），不报错、不残留失效路径

## 如何更新

- **已安装旧版本的用户**：点击左上角小铃铛或打开 **设置 › 通用 › 版本与更新 → 检查更新**，点击 **「立即更新」** 一键升级。
- **首次安装的用户**：访问官网 **`https://tingji.liwu.dpdns.org`** 或下载下方 **`SanqiuTingji-Setup.exe`** 双击安装即可。
